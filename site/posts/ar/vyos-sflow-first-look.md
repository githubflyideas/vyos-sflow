الألم أولًا 👇

جهاز VyOS عند مخرج مكتبنا يعمل منذ وقت طويل.
في كل يوم عمل، وقت الذروة، الشبكة تزحف.
من يأكل النطاق الترددي؟ لا أعرف.
أي جهاز، يتحدث مع أي خادم؟ لا أعرف أيضًا.
تخمين فقط. وكان الجواب دائمًا «جرّب إعادة التشغيل» 🙂

يستطيع VyOS تصدير عينات sFlow.
ومعظم المحولات والراوترات من ماركات أخرى والخوادم تستطيع أيضًا.

لكن ماذا بعد؟ لم يكن هناك شيء لمشاهدتها ❌
الأدوات المعتادة تريد خادمًا منفصلًا، أو قاعدة بيانات مع مجموعة لوحات كاملة.
هذا كثير جدًا، فقط لأرى حركة الشبكة عندي.

لذلك كتبت أداة صغيرة بنفسي. اسمها vyos-sflow ✨
ملف تنفيذي واحد.
شغّله على الراوتر نفسه،
أو ضعه على أي جهاز Linux ودع كل الأجهزة ترسل sFlow إليه.

## 📦 ثلاث خطوات للتثبيت

أولًا، شغّل sFlow في VyOS (تخطَّ هذا إذا كان يرسل أصلًا إلى 127.0.0.1:6343):

```
configure
set system sflow interface eth0
set system sflow server 127.0.0.1 port 6343
commit
save
exit
```

الجهاز ليس VyOS؟ الفكرة نفسها: وجّه تصدير sFlow في ذلك الجهاز إلى هذه الآلة، المنفذ 6343، وتابع أدناه.

ثم نزّله وشغّله:

```
curl -fLO https://github.com/githubflyideas/vyos-sflow/releases/download/v1.3.3/vyos-sflow-1.3.3-linux-amd64.tar.gz
tar -xzf vyos-sflow-1.3.3-linux-amd64.tar.gz
cd vyos-sflow-1.3.3-linux-amd64 && ./vyos-sflow serve
```

افتح `http://ROUTER_IP:8066` في المتصفح، سجّل الدخول بـ admin / tryvyossflow66، وغيّر كلمة المرور.
هذا كل شيء. تبدأ الرسوم بالامتلاء.

## 👀 ما الذي تحصل عليه

✅ النطاق الترددي الحالي، ومنحنى آخر 48 ساعة

✅ أكبر المستخدمين: أي عميل وأي خادم يستخدم الحركة أكثر، مرتبين

✅ حركة الواجهات من عدّادات الجهاز نفسه، بجانب تقدير العينات، لترى إن كانت الأرقام متطابقة

✅ سجلات التدفق خلف الرسوم — انقر أي قفزة واعرف صاحبها

✅ إذا كان الرسم فارغًا، صفحة Sources تخبرك بالسبب. بلا تخمين

![أكبر المستخدمين](assets/img/screenshots/vyos/web-top.png)

## 🖥️ لا متصفح؟ استخدم الطرفية

ادخل إلى الراوتر عبر SSH وشغّل أمرًا واحدًا:

```
./vyos-sflow tui
```

الصورة نفسها، في طرفيتك. اضغط q للخروج.
لا يُثبَّت شيء، مناسب لنظرة سريعة.

إضافات صغيرة: واجهة الويب تتحدث 15 لغة ولها خمسة مظاهر، من الفاتح إلى الداكن.

## ⚠️ الحدود بصراحة

- sFlow فقط. لا NetFlow ولا IPFIX
- السجل 48 ساعة. يجيب عن «ما الذي يحدث» و«ما الذي حدث للتو»، وليس للتقارير طويلة المدى
- Linux amd64 فقط. يغطي VyOS وخوادم Linux العادية، لكن لا توجد نسخة Windows أو macOS

إذا كانت هذه الثلاثة مناسبة لك، فهو يؤدي العمل جيدًا.

## 🔗 احصل عليه

مجاني ومفتوح المصدر، Apache-2.0.
ابحث في GitHub عن vyos-sflow، أو استخدم رابط التنزيل في هذا الموقع.
إن لم يعجبك، احذف المجلد ويختفي — الراوتر نفسه يبقى كما هو.

إذا كان VyOS يعمل كبوابة خروج لمكتبك أو بوابة لمقهى إنترنت، جرّبه.
شعور «أين ذهبت حركتي» يختفي.

ما الذي تستخدمه لمراقبة حركة الخروج عندك؟ أخبرني أدناه 👇
