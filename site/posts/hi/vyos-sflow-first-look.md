पहले दर्द सुनिए 👇

हमारे ऑफ़िस के एग्ज़िट पर लगा VyOS बॉक्स बहुत समय से चल रहा है।
हर वर्किंग डे, पीक टाइम पर नेटवर्क रेंगने लगता है।
बैंडविड्थ खा कौन रहा है? पता नहीं।
कौन-सी मशीन, किस सर्वर से बात कर रही है? यह भी पता नहीं।
बस अंदाज़ा। जवाब हमेशा एक ही — "रीबूट करके देखो" 🙂

VyOS sFlow सैंपल एक्सपोर्ट कर सकता है।
ज़्यादातर स्विच, दूसरे ब्रांड के राउटर और सर्वर भी कर सकते हैं।

लेकिन फिर क्या? उन्हें देखने के लिए कुछ था ही नहीं ❌
आम टूल्स को अलग सर्वर चाहिए, या डेटाबेस और पूरा डैशबोर्ड सेटअप।
सिर्फ़ अपना ट्रैफ़िक देखने के लिए यह बहुत ज़्यादा था।

तो मैंने खुद एक छोटा-सा टूल लिखा। नाम है vyos-sflow ✨
एक बाइनरी।
राउटर पर ही चलाइए,
या किसी भी Linux मशीन पर रख दीजिए और हर डिवाइस अपना sFlow वहाँ भेजे।

## 📦 इंस्टॉल के तीन स्टेप

पहले VyOS में sFlow चालू करें (अगर यह पहले से 127.0.0.1:6343 पर भेज रहा है तो यह स्टेप छोड़ दें):

```
configure
set system sflow interface eth0
set system sflow server 127.0.0.1 port 6343
commit
save
exit
```

डिवाइस VyOS नहीं है? तरीका वही है — उस डिवाइस का sFlow एक्सपोर्ट इस मशीन की ओर, पोर्ट 6343 पर कर दें, और नीचे जारी रखें।

फिर इसे डाउनलोड करके चलाएँ:

```
curl -fLO https://github.com/githubflyideas/vyos-sflow/releases/download/v1.3.3/vyos-sflow-1.3.3-linux-amd64.tar.gz
tar -xzf vyos-sflow-1.3.3-linux-amd64.tar.gz
cd vyos-sflow-1.3.3-linux-amd64 && ./vyos-sflow serve
```

`http://ROUTER_IP:8066` ब्राउज़र में खोलें, admin / tryvyossflow66 से साइन इन करें, और पासवर्ड बदल लें।
बस इतना ही। चार्ट भरने लगेंगे।

![ओवरव्यू पेज](assets/img/screenshots/vyos/web-overview.png)

## 👀 आपको क्या मिलता है

✅ अभी की बैंडविड्थ, और पिछले 48 घंटों का ग्राफ़

✅ टॉप टॉकर्स: कौन-सा क्लाइंट और कौन-सा सर्वर सबसे ज़्यादा ट्रैफ़िक इस्तेमाल करता है, रैंक के साथ

✅ इंटरफ़ेस ट्रैफ़िक डिवाइस के अपने काउंटर्स से, सैंपल वाले अनुमान के बगल में — ताकि आप देख सकें कि नंबर मेल खाते हैं या नहीं

✅ चार्ट्स के पीछे के फ़्लो रिकॉर्ड — स्पाइक पर क्लिक करें और पता करें वह कौन था

✅ अगर कोई चार्ट खाली है, तो Sources पेज बताता है क्यों। कोई अंदाज़ा नहीं

![टॉप टॉकर्स](assets/img/screenshots/vyos/web-top.png)

## 🖥️ ब्राउज़र नहीं है? टर्मिनल इस्तेमाल करें

राउटर में SSH करें और एक कमांड चलाएँ:

```
./vyos-sflow tui
```

वही तस्वीर, आपके टर्मिनल में। बाहर निकलने के लिए q दबाएँ।
कुछ इंस्टॉल नहीं होता, झटपट देखने के लिए बढ़िया है।

छोटी एक्स्ट्रा चीज़ें: वेब UI 15 भाषाओं में है और पाँच थीम हैं, हल्की से गहरी तक।

## ⚠️ ईमानदार सीमाएँ

- सिर्फ़ sFlow। NetFlow या IPFIX नहीं
- हिस्ट्री 48 घंटों की है। यह "अभी क्या हो रहा है" और "अभी-अभी क्या हुआ" बताता है, लंबे समय की रिपोर्टिंग नहीं
- सिर्फ़ Linux amd64। VyOS और आम Linux सर्वर इसमें आ जाते हैं, लेकिन Windows या macOS बिल्ड नहीं है

अगर ये तीनों बातें आपके लिए ठीक हैं, तो यह काम बखूबी करता है।
