먼저 아픈 얘기부터 👇

사무실 출구에 있는 VyOS가 돌아온 지 꽤 됐어요.
평일 피크 시간만 되면 네트워크가 기어갑니다.
누가 대역폭을 먹고 있는 거죠? 모릅니다.
어느 장비가, 어느 서버랑 얘기하는지? 그것도 모릅니다.
전부 추측뿐. 돌아오는 답은 늘 "재부팅해 보세요" 🙂

VyOS는 sFlow 샘플을 내보낼 수 있어요.
스위치, 다른 회사 라우터, 서버도 대부분 내보낼 수 있고요.

그런데 그다음은요? 볼 수 있는 게 아무것도 없었어요 ❌
보통 도구들은 별도 서버를 요구하거나, 데이터베이스와 대시보드 스택 전체를 요구해요.
제 트래픽 한번 보려는 건데, 너무 무거웠습니다.

그래서 작은 도구를 직접 만들었어요. 이름은 vyos-sflow입니다 ✨
바이너리 하나예요.
라우터 자체에서 돌려도 되고,
Linux 머신 하나에 올려서 모든 장비의 sFlow를 받아도 됩니다.

## 📦 설치는 세 단계

먼저 VyOS에서 sFlow를 켜세요(이미 127.0.0.1:6343으로 보내고 있다면 건너뛰세요).

```
configure
set system sflow interface eth0
set system sflow server 127.0.0.1 port 6343
commit
save
exit
```

VyOS 장비가 아니어도 같아요. 그 장비의 sFlow를 이 머신의 6343 포트로 보내게 하고, 아래를 그대로 따라 하면 됩니다.

그다음 다운로드해서 실행하세요.

```
curl -fLO https://github.com/githubflyideas/vyos-sflow/releases/download/v1.3.3/vyos-sflow-1.3.3-linux-amd64.tar.gz
tar -xzf vyos-sflow-1.3.3-linux-amd64.tar.gz
cd vyos-sflow-1.3.3-linux-amd64 && ./vyos-sflow serve
```

브라우저에서 `http://ROUTER_IP:8066`을 열고, admin / tryvyossflow66으로 로그인한 뒤 비밀번호를 바꾸세요.
그게 전부예요. 차트에 데이터가 채워지기 시작합니다.

## 👀 무엇을 볼 수 있나요

✅ 현재 대역폭과 지난 48시간의 곡선

✅ 트래픽 상위 호스트: 어떤 클라이언트와 어떤 서버가 트래픽을 가장 많이 쓰는지 순위로 표시

✅ 샘플링 추정치 옆에 기기 자체 카운터로 잰 인터페이스 트래픽을 함께 표시해서, 숫자가 맞는지도 확인할 수 있어요

✅ 차트 뒤에 있는 플로우 기록 — 스파이크를 클릭하면 누구였는지 알 수 있어요

✅ 차트가 비어 있으면 Sources 페이지가 이유를 알려줘요. 추측할 필요가 없어요

## 🖥️ 브라우저가 없으면 터미널로

라우터에 SSH로 접속해서 명령 하나만 실행하세요.

```
./vyos-sflow tui
```

같은 그림이 터미널 안에 나옵니다. q를 누르면 종료돼요.
아무것도 설치하지 않으니, 잠깐 볼 때 딱 좋습니다.

작은 덤: 웹 UI는 15개 언어를 지원하고, 라이트부터 다크까지 테마가 다섯 가지예요.

## ⚠️ 솔직한 한계

- sFlow만 됩니다. NetFlow, IPFIX는 안 돼요
- 기록은 48시간입니다. "지금 무슨 일이 일어나고 있나"와 "방금 무슨 일이 있었나"에 답하는 도구예요. 장기 리포트용은 아닙니다
- Linux amd64만 됩니다. VyOS와 일반 Linux 서버는 커버하지만, Windows나 macOS 빌드는 없어요

이 세 가지가 괜찮다면, 제 역할은 충분히 합니다.
