پہلے درد سن لیں 👇

ہمارے دفتر کے ایگزٹ پر لگا VyOS کافی عرصے سے چل رہا ہے۔
ہر کام کے دن عروج کے اوقات میں نیٹ ورک سست پڑ جاتا ہے۔
بینڈوڈتھ کون کھا رہا ہے؟ کوئی اندازہ نہیں۔
کون سی مشین، کس سرور سے بات کر رہی ہے؟ یہ بھی نہیں معلوم۔
بس اندازے۔ جواب ہمیشہ یہی تھا: "ری بوٹ کر کے دیکھو" 🙂

VyOS sFlow سیمپل ایکسپورٹ کر سکتا ہے۔
زیادہ تر سوئچ، دوسرے برانڈز کے راؤٹر اور سرور بھی کر سکتے ہیں۔

لیکن اس کے بعد؟ انہیں دیکھنے کے لیے کچھ تھا ہی نہیں ❌
عام ٹولز کو الگ سرور چاہیے ہوتا ہے، یا ڈیٹا بیس اور ڈیش بورڈز کا پورا سیٹ اپ۔
صرف اپنی ٹریفک دیکھنے کے لیے یہ بہت زیادہ تھا۔

اس لیے میں نے خود ایک چھوٹا سا ٹول لکھا۔ اس کا نام vyos-sflow ہے ✨
ایک بائنری۔
اسے راؤٹر پر ہی چلا لیں،
یا کسی بھی Linux مشین پر رکھ دیں اور سارے ڈیوائس اپنا sFlow وہیں بھیجیں۔

## 📦 انسٹال کے تین مراحل

پہلے VyOS میں sFlow آن کریں (اگر یہ پہلے سے 127.0.0.1:6343 پر بھیج رہا ہے تو یہ مرحلہ چھوڑ دیں):

```
configure
set system sflow interface eth0
set system sflow server 127.0.0.1 port 6343
commit
save
exit
```

ڈیوائس VyOS نہیں ہے؟ طریقہ وہی ہے: اس ڈیوائس کا sFlow ایکسپورٹ اس مشین کی طرف، پورٹ 6343 پر، کر دیں اور نیچے جاری رکھیں۔

پھر اسے ڈاؤن لوڈ کر کے چلائیں:

```
curl -fLO https://github.com/githubflyideas/vyos-sflow/releases/download/v1.3.3/vyos-sflow-1.3.3-linux-amd64.tar.gz
tar -xzf vyos-sflow-1.3.3-linux-amd64.tar.gz
cd vyos-sflow-1.3.3-linux-amd64 && ./vyos-sflow serve
```

براؤزر میں `http://ROUTER_IP:8066` کھولیں، admin / tryvyossflow66 سے سائن ان کریں اور پاس ورڈ بدل لیں۔
بس اتنا ہی۔ چارٹس بھرنا شروع ہو جاتے ہیں۔

![اوورویو صفحہ](assets/img/screenshots/vyos/web-overview.png)

## 👀 آپ کو کیا ملتا ہے

✅ موجودہ بینڈوڈتھ، اور پچھلے 48 گھنٹوں کا گراف

✅ سب سے زیادہ استعمال کرنے والے: کون سا کلائنٹ اور کون سا سرور سب سے زیادہ ٹریفک استعمال کرتا ہے، ترتیب سے

✅ انٹرفیس ٹریفک ڈیوائس کے اپنے کاؤنٹرز سے، سیمپلنگ کے اندازے کے ساتھ ساتھ — نظر آ جاتا ہے کہ نمبر ملتے ہیں یا نہیں

✅ چارٹس کے پیچھے موجود فلو ریکارڈز: کسی چوٹی پر کلک کریں اور پتا چل جائے کہ وہ کون تھا

✅ اگر کوئی چارٹ خالی ہو تو Sources صفحہ وجہ بتا دیتا ہے۔ اندازے ختم

![سب سے زیادہ استعمال کرنے والے](assets/img/screenshots/vyos/web-top.png)

## 🖥️ براؤزر نہیں ہے؟ ٹرمینل استعمال کریں

راؤٹر میں SSH کریں اور ایک کمانڈ چلائیں:

```
./vyos-sflow tui
```

وہی منظر، آپ کے ٹرمینل میں۔ نکلنے کے لیے q دبائیں۔
کچھ انسٹال نہیں ہوتا، فوری جائزے کے لیے بہترین ہے۔

چھوٹی اضافی باتیں: ویب انٹرفیس 15 زبانوں میں ہے اور اس کی پانچ تھیمز ہیں، ہلکی سے گہری تک۔

## ⚠️ ایماندارانہ حدود

- صرف sFlow۔ NetFlow اور IPFIX نہیں
- ہسٹری 48 گھنٹے کی ہے۔ یہ "اب کیا ہو رہا ہے" اور "ابھی ابھی کیا ہوا" کا جواب دیتا ہے، طویل مدتی رپورٹنگ کا نہیں
- صرف Linux amd64۔ VyOS اور عام Linux سرورز کے لیے کافی ہے، لیکن Windows یا macOS کی بلڈ نہیں ہے

اگر یہ تین باتیں آپ کو قبول ہیں تو یہ اپنا کام خوب کرتا ہے۔
