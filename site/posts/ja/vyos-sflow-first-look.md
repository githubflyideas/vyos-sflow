まず悩みから👇

オフィスの出口にあるVyOSは、もう長く動いています。
平日のピークになると、ネットワークが激重。
誰が帯域を食ってるの？ 分からない。
どのマシンが、どのサーバーと？ それも分からない。
全部、勘。返ってくるのはいつも「再起動してみて」🙂

VyOSはsFlowのサンプルを出せます。
スイッチも、他のメーカーのルーターも、サーバーも、大抵は出せます。

でも、その先は？ 見るものが何もなかったんです❌
よくあるツールは、別にサーバーが要ったり、データベースとダッシュボード一式が要ったり。
自分のトラフィックを見たいだけなのに、重すぎます。

なので、小さなツールを自分で書きました。vyos-sflowといいます✨
バイナリ1つ。
ルーター自体の上で動かしてもいいし、
Linuxマシン1台に置いて、全部の機器のsFlowを集めてもいい。

## 📦 インストールは3ステップ

まず、VyOSでsFlowを有効にします（すでに127.0.0.1:6343へ送っている場合はスキップしてください）。

```
configure
set system sflow interface eth0
set system sflow server 127.0.0.1 port 6343
commit
save
exit
```

VyOS以外の機器でも同じです。その機器のsFlowの送り先をこのマシンの6343番ポートにして、以下同じように進めてください。

次に、ダウンロードして実行します。

```
curl -fLO https://github.com/githubflyideas/vyos-sflow/releases/download/v1.3.3/vyos-sflow-1.3.3-linux-amd64.tar.gz
tar -xzf vyos-sflow-1.3.3-linux-amd64.tar.gz
cd vyos-sflow-1.3.3-linux-amd64 && ./vyos-sflow serve
```

ブラウザで `http://ROUTER_IP:8066` を開いて、admin / tryvyossflow66 でログインし、パスワードを変更してください。
それだけです。グラフにデータがたまり始めます。

## 👀 見られるもの

✅ 現在の帯域と、過去48時間のグラフ

✅ トップトーカー：どのクライアントとどのサーバーが一番トラフィックを使っているか、ランキングで表示

✅ デバイス自体のカウンタによるインターフェーストラフィックを、サンプリングの推定値と並べて表示。数字が合っているか確認できます

✅ グラフの裏にあるフロー記録。スパイクをクリックすれば、誰だったのか分かります

✅ グラフが空でも、Sourcesページが理由を教えてくれます。当てずっぽうは不要です

## 🖥️ ブラウザがなければ、ターミナルで

ルーターにSSHで入って、コマンドを1つ実行します。

```
./vyos-sflow tui
```

同じ画面が、ターミナルの中に。qを押せば終了。
何もインストールしないので、ちょっと見たいときに便利です。

小さな追加：Web UIは15言語対応で、テーマはライトからダークまで5種類あります。

## ⚠️ 正直な制限

- sFlowのみです。NetFlow、IPFIXには対応していません
- 履歴は48時間です。「今何が起きているか」「さっき何が起きたか」に答えるもので、長期レポート用ではありません
- Linux amd64のみです。VyOSと普通のLinuxサーバーはカバーしますが、WindowsやmacOS向けのビルドはありません

この3つが問題なければ、しっかり役に立ちます。
