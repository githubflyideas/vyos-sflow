Сначала боль 👇

VyOS на выходе нашей офисной сети работает уже давно.
Каждый будний день в час пик сеть ползёт.
Кто съедает полосу? Понятия не имею.
Какая машина и с каким сервером разговаривает? Тоже непонятно.
Одни догадки. Ответ был всегда один: «перезагрузи» 🙂

VyOS умеет отдавать сэмплы sFlow.
Большинство коммутаторов, роутеров других марок и серверов — тоже.

А дальше что? Посмотреть их было нечем ❌
Обычные инструменты хотят отдельный сервер, а то и базу данных с целой панелью дашбордов.
Слишком много, чтобы просто глянуть собственный трафик.

Поэтому я написал маленький инструмент сам. Называется vyos-sflow ✨
Один бинарник.
Запускайте прямо на роутере —
или на любой Linux-машине, куда все устройства шлют свой sFlow.

## 📦 Установка в три шага

Сначала включите sFlow на VyOS (пропустите, если он уже шлёт на 127.0.0.1:6343):

```
configure
set system sflow interface eth0
set system sflow server 127.0.0.1 port 6343
commit
save
exit
```

Устройство не VyOS? Идея та же: направьте его экспорт sFlow на эту машину, порт 6343, и продолжайте ниже.

Затем скачайте и запустите:

```
curl -fLO https://github.com/githubflyideas/vyos-sflow/releases/download/v1.3.3/vyos-sflow-1.3.3-linux-amd64.tar.gz
tar -xzf vyos-sflow-1.3.3-linux-amd64.tar.gz
cd vyos-sflow-1.3.3-linux-amd64 && ./vyos-sflow serve
```

Откройте `http://IP_РОУТЕРА:8066` в браузере, войдите как admin / tryvyossflow66 и смените пароль.
Это всё. Графики начинают заполняться.

## 👀 Что вы получаете

✅ Текущую полосу и кривую за последние 48 часов

✅ Топ потребителей: какой клиент и какой сервер используют больше всего трафика, по порядку

✅ Трафик интерфейсов по собственным счётчикам устройства — рядом с оценкой по сэмплам, видно, сходятся ли цифры

✅ Записи потоков за графиками: кликнули по пику — узнали, кто это был

✅ Если график пустой, страница Sources объяснит почему. Без догадок

## 🖥️ Нет браузера? Есть терминал

Зайдите на роутер по SSH и выполните одну команду:

```
./vyos-sflow tui
```

Та же картинка, прямо в терминале. Выход — клавиша q.
Ничего не устанавливается — удобно для быстрой проверки.

Мелочи: веб-интерфейс говорит на 15 языках, в нём пять тем, от светлой до тёмной.

## ⚠️ Честные ограничения

- Только sFlow. Без NetFlow и IPFIX
- История — 48 часов. Отвечает на «что происходит» и «что только что было», а не на отчётность за месяцы
- Только Linux amd64. Этого хватает для VyOS и обычных Linux-серверов, но сборки для Windows и macOS нет

Если эти три пункта вас устраивают — работает отлично.
