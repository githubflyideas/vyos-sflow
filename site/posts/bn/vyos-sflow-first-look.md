আগে কষ্টের কথা 👇

আমাদের অফিসের এগ্জিটে বসানো VyOS বক্সটা অনেকদিন ধরে চলছে।
প্রতিটা কর্মদিবসে, পিক টাইমে, নেটওয়ার্ক হামাগুড়ি দেয়।
ব্যান্ডউইথ খাচ্ছে কে? জানি না।
কোন মেশিন, কোন সার্ভারের সঙ্গে কথা বলছে? তাও জানি না।
শুধু আন্দাজ। উত্তর সবসময় একটাই — "রিবুট করে দেখো" 🙂

VyOS sFlow স্যাম্পল এক্সপোর্ট করতে পারে।
বেশিরভাগ সুইচ, অন্য ব্র্যান্ডের রাউটার আর সার্ভারও পারে।

কিন্তু তারপর কী? দেখার মতো কিছুই ছিল না ❌
পরিচিত টুলগুলোর আলাদা সার্ভার লাগে, বা ডেটাবেস আর ড্যাশবোর্ডের পুরো সেটআপ।
শুধু নিজের ট্রাফিক দেখতে এটা অনেক বেশি।

তাই আমি নিজেই একটা ছোট টুল লিখলাম। নাম vyos-sflow ✨
একটাই বাইনারি।
রাউটারের উপরেই চালান,
অথবা যেকোনো Linux মেশিনে বসান আর সব ডিভাইস সেখানে sFlow পাঠাক।

## 📦 ইনস্টলের তিন ধাপ

প্রথমে VyOS-এ sFlow চালু করুন (আগে থেকেই 127.0.0.1:6343-তে পাঠালে এই ধাপ বাদ দিন):

```
configure
set system sflow interface eth0
set system sflow server 127.0.0.1 port 6343
commit
save
exit
```

ডিভাইসটা VyOS নয়? পদ্ধতি একই — ওই ডিভাইসের sFlow এক্সপোর্ট এই মেশিনের দিকে, পোর্ট 6343-এ করে দিন, আর নিচে এগিয়ে যান।

তারপর ডাউনলোড করে চালান:

```
curl -fLO https://github.com/githubflyideas/vyos-sflow/releases/download/v1.3.3/vyos-sflow-1.3.3-linux-amd64.tar.gz
tar -xzf vyos-sflow-1.3.3-linux-amd64.tar.gz
cd vyos-sflow-1.3.3-linux-amd64 && ./vyos-sflow serve
```

ব্রাউজারে `http://ROUTER_IP:8066` খুলুন, admin / tryvyossflow66 দিয়ে সাইন ইন করুন, আর পাসওয়ার্ড বদলে নিন।
ব্যাস, এটুকুই। চার্ট ভরতে শুরু করবে।

![ওভারভিউ পেজ](assets/img/screenshots/vyos/web-overview.png)

## 👀 আপনি যা পাবেন

✅ এখনকার ব্যান্ডউইথ, আর গত 48 ঘণ্টার গ্রাফ

✅ টপ টকার্স: কোন ক্লায়েন্ট আর কোন সার্ভার সবচেয়ে বেশি ট্রাফিক ব্যবহার করে, ক্রম অনুযায়ী

✅ ডিভাইসের নিজের কাউন্টার থেকে ইন্টারফেস ট্রাফিক, স্যাম্পল-ভিত্তিক হিসাবের পাশাপাশি — যাতে দেখতে পারেন সংখ্যাগুলো মিলছে কি না

✅ চার্টের পেছনের ফ্লো রেকর্ড — স্পাইকে ক্লিক করুন আর জেনে নিন ওটা কে ছিল

✅ কোনো চার্ট খালি থাকলে Sources পেজ বলে দেয় কেন। আন্দাজের দরকার নেই

![টপ টকার্স](assets/img/screenshots/vyos/web-top.png)

## 🖥️ ব্রাউজার নেই? টার্মিনাল ব্যবহার করুন

রাউটারে SSH করে একটা কমান্ড চালান:

```
./vyos-sflow tui
```

একই ছবি, আপনার টার্মিনালে। বের হতে q চাপুন।
কিছুই ইনস্টল হয় না, চট করে দেখার জন্য দারুণ।

ছোট্ট বাড়তি: ওয়েব UI 15টি ভাষায় আছে আর পাঁচটা থিম আছে, হালকা থেকে গাঢ়।

## ⚠️ সৎ সীমাবদ্ধতা

- শুধু sFlow। NetFlow বা IPFIX নয়
- হিস্ট্রি 48 ঘণ্টার। এটি "এখন কী হচ্ছে" আর "এইমাত্র কী হলো" বলে, দীর্ঘমেয়াদি রিপোর্টিং নয়
- শুধু Linux amd64। VyOS আর সাধারণ Linux সার্ভার এতে চলে, কিন্তু Windows বা macOS বিল্ড নেই

এই তিনটে আপনার জন্য ঠিক থাকলে, এটি কাজটা ভালোই করে।
