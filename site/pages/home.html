See your sFlow traffic, on your own machine

vyos-sflow collects the sFlow your VyOS router already exports — most switches, other routers and servers can send theirs too — and turns it into bandwidth charts, top talkers and flow records — in a browser dashboard, or in a terminal over SSH. One binary, nothing else to install, deployed in 30 seconds.

DownloadQuick startBlog

What it does

Runs where the traffic is

Install it on the VyOS router itself, or on any Linux box that receives sFlow. No separate monitoring server, no database to set up.

Bandwidth and top talkers

Live bandwidth, the clients and servers using it, and the recent flow records behind the numbers.

Checked against the device

Interface traffic comes from the device's own counters, shown next to the sampled estimate, so you can see whether the numbers line up.

A terminal view over SSH

./vyos-sflow tui opens the same picture in your SSH session. No browser, no service install — look, then quit with q.

48 hours of history

Kept locally with an embedded database. Long enough to answer "when did this start?" — and nothing leaves the router.

Read it your way

Web UI in 15 languages and five themes, from light to dark. The terminal view speaks the same language.
